# Fitur "Butuh bantuan?" — Help Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambahkan link "Butuh bantuan?" di sidebar dashboard (di atas menu profile user) yang membuka halaman `/dashboard/help` berisi kontak dukungan + FAQ.

**Architecture:** Statik penuh, tanpa backend/tRPC. Link di `SidebarFooter` (`app-sidebar.tsx`) → route `/dashboard/help` → komponen `HelpPage` dari feature `features/help/`. Kontak & FAQ di file data terpisah.

**Tech Stack:** Next.js App Router, React 19, Tailwind v4, shadcn/ui (`Card`, `Accordion`, `Button`), lucide-react.

## Global Constraints

- Bahasa UI: Bahasa Indonesia.
- Ikon lucide-react pakai suffix `Icon` (mis. `HelpCircleIcon`), konsisten dengan codebase.
- `@/*` path alias ke root project.
- Layout dashboard (`app/(dashboard)/dashboard/layout.tsx`) sudah handle auth — halaman baru tidak perlu auth check sendiri.
- Kontak pakai placeholder `https://t.me/zyvo` & `halo@zyvo.id` (user ganti nanti di `features/help/lib/contact.ts`).
- Jangan tambah dependency baru.
- Jangan tambah comment.

### Task 3: Halaman `/dashboard/help`

**Files:**
- Create: `features/help/components/help-page.tsx`
- Create: `app/(dashboard)/dashboard/help/page.tsx`

**Interfaces:**
- Consumes: `SUPPORT_CONTACT` & `HELP_FAQS` dari Task 1 (`features/help/lib/contact.ts`, `features/help/lib/faq-data.ts`). Path `/dashboard/help` dari Task 2.
- Produces: halaman siap pakai di `/dashboard/help`.

- [ ] **Step 1: Buat `features/help/components/help-page.tsx`**

```tsx
import { HelpCircleIcon, MailIcon, SendIcon } from "lucide-react";
import Link from "next/link";
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";
import { Button } from "@/components/ui/button";
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card";
import { HELP_FAQS } from "@/features/help/lib/faq-data";
import { SUPPORT_CONTACT } from "@/features/help/lib/contact";

export function HelpPage() {
  return (
    <div className="mx-auto w-full max-w-2xl space-y-6">
      <div>
        <h1 className="text-3xl font-bold">Butuh bantuan?</h1>
        <p className="mt-1 text-sm text-muted-foreground">
          Temukan jawaban pertanyaan umum atau hubungi tim dukungan kami.
        </p>
      </div>

      <Card className="rounded-2xl">
        <CardHeader>
          <CardTitle className="text-lg font-bold">Hubungi dukungan</CardTitle>
          <p className="text-sm text-muted-foreground">
            Belum menemukan jawaban? Tim kami siap membantu.
          </p>
        </CardHeader>
        <CardContent className="flex flex-wrap gap-2">
          <Button
            nativeButton={false}
            render={<Link href={SUPPORT_CONTACT.telegramUrl} target="_blank" />}
          >
            <SendIcon className="size-4" />
            Telegram
          </Button>
          <Button
            nativeButton={false}
            variant="outline"
            render={<Link href={`mailto:${SUPPORT_CONTACT.email}`} />}
          >
            <MailIcon className="size-4" />
            {SUPPORT_CONTACT.email}
          </Button>
        </CardContent>
      </Card>

      <Card className="rounded-2xl">
        <CardHeader>
          <CardTitle className="text-lg font-bold">Pertanyaan umum</CardTitle>
        </CardHeader>
        <CardContent>
          <Accordion type="single" collapsible>
            {HELP_FAQS.map((faq, i) => (
              <AccordionItem key={faq.q} value={`item-${i}`}>
                <AccordionTrigger className="text-sm font-medium hover:no-underline">
                  {faq.q}
                </AccordionTrigger>
                <AccordionContent className="text-sm text-muted-foreground">
                  {faq.a}
                </AccordionContent>
              </AccordionItem>
            ))}
          </Accordion>
        </CardContent>
      </Card>

      <p className="flex items-center gap-2 text-xs text-muted-foreground">
        <HelpCircleIcon className="size-4" />
        Tips: banyak pertanyaan umum sudah terjawab di FAQ di atas.
      </p>
    </div>
  );
}
```
